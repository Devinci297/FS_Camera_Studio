FS CAMERA STUDIO - VERSION 0.5.1
Microsoft Flight Simulator 2024 and X-Plane 12 | Windows 11 x64

INSTALL
1. Close Microsoft Flight Simulator 2024 (and X-Plane, if you install for it).
2. Run the included FS-Camera-Studio-...-Setup.exe under your normal Windows
   account. No SDK, Python, Node, external app or background service is needed.
   On the components page choose MSFS 2024, X-Plane 12 or both. For X-Plane
   see INSTALL FOR X-PLANE 12 below.
3. Confirm the detected Community / Community2024 folder, or Browse to it.
   Steam, Microsoft Store / Xbox app and custom package locations are supported.
   If no folder is detected, launch MSFS once. Use the simulator's Community
   folder location to find the correct folder; do not choose the add-on folder.
4. Finish setup, then start MSFS and load a flight.
5. Open Camera Studio from the MSFS toolbar. The mini panel appears at the
   bottom of the simulator window. Enable the toolbar item if it is hidden.

INSTALL FOR X-PLANE 12 (XP CAMERA STUDIO)
1. Close X-Plane. X-Plane 12.4.4 or newer is required.
2. Choose X-Plane 12 on the components page and confirm the detected X-Plane 12
   folder (the one that contains X-Plane.exe), or Browse to it. Steam and
   standalone installs are supported. Setup puts the plugin in
   Resources\plugins\XPCameraStudio and backs up an older copy first.
3. Start X-Plane and load a flight. Open Plugins > XP Camera Studio > Editor.
   The mini panel shows when the mouse reaches the bottom of the screen.
4. For camera-view keys, choose Assign key binding in XPCS, select your native
   controls profile, capture a key and review conflicts, then Assign after exit.
   The bundled helper backs up preferences and removes conflicting assignments
   after X-Plane closes. Keys take effect on the next launch. Other commands
   and controller buttons use X-Plane Settings > Keyboard or Joystick.
5. Profiles are saved in X-Plane 12\Output\preferences\XPCameraStudio and are
   kept on upgrade and uninstall. Profiles > Import also converts X-Camera
   camera files for the loaded aircraft.
Log lines start with "XP Camera Studio:" in X-Plane 12\Log.txt; include them
when you report an X-Plane problem.

This tester installer is not code-signed. Windows may show an unknown-publisher
or SmartScreen message. Confirm you received it from the developer and compare
the SHA-256 against the separately supplied checksum before choosing to run it.
Do not disable antivirus or Windows protection settings.

FIRST FLIGHT
- Use a familiar aircraft and a parked flight for the first check.
- Select a camera, then View in sim / Enable camera.
- Camera directions are configured automatically. No axis calibration is required.
- Hold right mouse and drag in the simulator scene to look around.
- W/S moves forward/back along the view, A/D sideways, Q up, E down.
- Shift moves faster. Mouse wheel zooms. Fine/Normal/Coarse changes precision.
- Ctrl+S saves the adjusted active view and all pending changes. Bindings are
  editable in the Bindings tab; existing conflicting assignments are preserved.
- Mouse look opens options to retain the adjusted look or reset on release,
  and to remember/reset temporary look when recalling that camera.
- Release camera returns control to MSFS.

AIRPORT CAMERAS
Camera library + > Create airport cameras. Choose a nearby airport or enter
ICAO codes, choose features and placement, then Preview and Save selected views.
Runways, gates/apron, towers and offset taxiway intersections use scenery data.
Optional airport XML supplies actual taxi-sign positions. Only the current,
nearest or manually selected nearby saved airport is loaded alongside the
aircraft profile.

Airport views can be repositioned with the editor or movement bindings. Track
lets you choose fixed direction, aircraft heading, or heading and pitch. Auto
switch on the mini toolbar chooses the nearest camera while camera control is
active. Manual movement and right-drag pause it briefly; the global toggle
remains enabled across cameras. Release camera pauses switching.
Settings > Airport defaults provides horizon protection, auto zoom with framing/FOV
limits/response, and separate heights for runways, gates, apron, taxi and tower.
Airport camera settings overrides each value independently. Missing values inherit
the global default. Distant lower targets can be kept near the horizon; this does
not remove terrain or building occlusion.
The mini toolbar also has Save; longer camera lists scroll.

HEAD TRACKING
Head tracking is global and OFF by default. Use its button to enable the MSFS
TrackIR-compatible channel for all cameras and profiles. Aircraft tracking is
also global and defaults to heading + pitch; cockpit views never track aircraft.
Assign Toggle head tracking in Bindings if desired. The add-on does not include
tracking hardware/drivers and does not control VR or independent camera tools.
Physical hardware behavior still needs tester verification.

UPGRADE / REPAIR
The app bar shows the version. Click it for Version & updates in Settings.
Check for updates queries official GitHub releases; Download update opens the
installer in your browser. A selectable URL is provided if browser launch is
unavailable. Close MSFS before running setup. Automatic checks can be disabled.
The illustrated User manual is included and available in Start > FS Camera Studio.

Close MSFS and run the newer setup over the same Community location. Setup
backs up an existing package under:
  %LOCALAPPDATA%\FS Camera Studio\Backups
LAST-BACKUP.txt in that folder's parent identifies the latest backup. Re-running
setup repairs the shipped package files. Profiles, airports, settings and
bindings are stored by MSFS outside the installed package and are not removed.
Export valuable profiles using Profiles > Export profile before testing.
Version 0.4.0 saves profiles in schema 4, which 0.3.0 cannot read. Export
profiles BEFORE upgrading if you might roll back to 0.3.0.

Only install ONE copy. A package managed by Addons Linker or a development
junction must be disabled/removed as a link before using this installer.
Setup deliberately refuses to overwrite linked package directories.
If your chosen Community folder is protected, use a writable simulator package
location. Do not run setup as a different Windows account.

UNINSTALL / ROLLBACK
Close MSFS and X-Plane. Windows Settings > Apps > Installed apps > FS Camera
Studio (Tester) > Uninstall. This removes installer-owned files (the MSFS
package and the X-Plane plugin) and preserves profile storage in both
simulators, backups and any additional files you placed in the package directory.

For rollback: after uninstalling, copy the entire fs-camera-studio folder from
the desired backup into your Community folder. Ensure only one copy is active.
Do not restore files while the simulator is running.

WHAT TO TEST / REPORT
This is a test build, not a stability-certified release. Offline native and
browser checks have passed; flight loading, live movement, airport cameras and
physical head tracking still need simulator testing. Airport elevations depend
on scenery data. Exterior views may retain cockpit sound.

Check: flight loading; cockpit clicks and MSFS toolbar hover; right-drag
smoothness; pitched WASD and Q/E; temporary-look reset/recall; Ctrl+S and view
recall; bindings past slot 20; airport generation/movement/tracking/Auto switch;
scrolling long mini lists; head tracking on/off; upgrade persistence.

Send the developer:
- Build ID from BUILD-INFO.json supplied with the download or installed at
  %LOCALAPPDATA%\FS Camera Studio\BUILD-INFO.json
- MSFS version, aircraft, airport ICAO and scenery add-ons.
- Exact steps, expected/actual behavior, and screenshot/video if useful.
- For crashes: whether loading, opening the panel or a specific action caused it.
- For install errors: the newest Setup Log in %TEMP%.
Review logs before sharing; paths may contain your Windows username.

No profiles, credentials or data from the developer's computer are bundled.

INCLUDED FEATURES
- Main and mini background opacity have independent sliders in Settings.
- Main editor always displays icons and labels. Mini display affects categories.
- Hold adjustment buttons to repeat; release or loss of focus stops movement.
- Library + > External motion views adds Orbit, Fly-by and Walkaround views.
- Profile import: copy the displayed folder path into Explorer, add JSON files,
  then Refresh, select a file and Import. Pasting profile code is also supported.
- Successful saves request a native confirmation chime. Settings > Test sound
  checks the simulator UI sound route; spoken WAV is browser-only.

NEW IN VERSION 0.5.1
- Profiles hold up to 2,000 cameras; airport generation still stops at 500.
- Move, rotate and zoom while watching traffic. Mouse look opens traffic camera
  controls; Recenter restores framing. Adjusting stops Auto-spot switching.
- Native camera keys can be assigned, changed or removed from XPCS. Choose the
  X-Plane controls profile explicitly, review conflicts, then Assign after exit.
  Effective next launch; selected preferences are backed up before changes.
- Automated checks passed; live simulator acceptance of this patch is pending.

NEW IN VERSION 0.5.0
- X-Plane 12 support: XP Camera Studio, the same editor, mini panel, cameras,
  airport cameras and spotting as a native X-Plane 12 plugin (12.4.4 or newer).
  See INSTALL FOR X-PLANE 12 above.
- One setup for both simulators: choose MSFS 2024, X-Plane 12 or both.
- In X-Plane every action is an xpcs/ command; the Bindings tab lists them with
  Copy. Airports come from X-Plane's apt.dat scenery, traffic from X-Plane's
  TCAS targets, and Profiles > Import converts X-Camera camera files.
- MSFS: messages and update hints name the simulator in use. No other MSFS
  behavior changes; 0.5.0 reads and writes the same schema 4 profiles as 0.4.0.

Please check in 0.5.0 (X-Plane): setup finds your X-Plane 12 folder; the editor
and mini panel open; cockpit and exterior views; airport cameras at your home
airport; spotting AI or multiplayer traffic; assigning xpcs/ commands to keys;
X-Camera import if you use X-Camera; uninstall leaves other plugins alone.

NEW IN VERSION 0.4.0
- Camera feel: per-camera Follow horizon slider (0 follows bank, 1 stays level),
  flight effects on exterior and orbit views at half strength with Off / Subtle /
  Realistic / Action presets, cockpit head movement (lag, turn lean, taxi bob,
  optional idle sway) and a Mounted action cam mode with gimbal and vibration.
- New default keys (all Ctrl+Alt): X panic release, Z hold for binoculars,
  G hold to glance / I next glance / U return, K cinematic mode, T / Y next and
  previous traffic target, O return to own aircraft, J auto-spot. Existing custom
  bindings are kept; check Bindings if a new default is missing.
- Cinematic mode picks views by flight phase and holds each 8-20 s (Settings).
- Nearby airports without saved cameras get temporary tower, runway, stand and
  spotting views. Use Save in the library to keep them.
- Drop drone here creates a world-fixed free camera. Fly it with the movement
  keys or an Xbox-style gamepad (left stick moves, right stick looks, triggers
  climb/descend). Settings > Gamepad assigns other axes. Throttles, sticks and
  pedals are never picked automatically.
- Traffic tab and mini Traffic tab: follow AI / FSLTL / VATSIM / IVAO /
  SayIntentions traffic from tower, runway, chase, fly-by, track or saved spots.
  Tower and runway views need no airport cameras or profile. The mini tab has
  All / Departures / Arrivals / On ground / Cruise filters and a search box.
  MSFS's own multiplayer aircraft are not visible to add-ons.
- Pop out (beside Compact) moves the editor to its own window for another
  monitor, when the simulator allows it. Dock brings it back.
- Click the mini panel's category divider to show categories as icons only.

Please check in 0.4.0: head movement strength; mounted cam pitch direction;
binoculars; cinematic phase changes; temporary airport views; drone flight and
terrain floor; gamepad detection and that the aircraft ignores the sticks only
while a drone is shown; chase / fly-by smoothness on moving traffic; runway end
choice for arrivals and departures; editing and saving spots; Pop out; the mini
Traffic filters.
