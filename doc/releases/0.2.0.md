# FS Camera Studio 0.2.0

Download **FS-Camera-Studio-0.2.0-Setup.exe**, close MSFS, and run setup over the existing installation. Saved profiles, airport cameras, bindings and settings are preserved. Existing tester builds can find this release through **Settings > Check for updates**.

## Changes

- Independent main and mini background opacity from 0 to 100%, with native simulator blur disabled; larger mini category buttons, simple SVG icons and feature-specific airport icons. The main editor always shows icons and labels.
- Compact camera context, mouse-look, walkaround and delete dialogs; copy/paste camera settings; hold position buttons to adjust repeatedly, with stop on release or focus loss.
- Global head tracking defaults off; global aircraft tracking defaults to heading and pitch for airport and exterior views. Camera and profile changes preserve these choices; cockpit views never track aircraft.
- Global airport auto-switch with active-camera highlighting. Improved camera movement, key release handling and temporary-look behavior.
- Airport libraries are shared by all aircraft and work without an aircraft profile. Airport edits survive aircraft-profile changes. Regeneration can replace existing generated views and discard that airport's edits after a warning, preserving other airports and aircraft views.
- Library **+ > External motion views** adds orbit, an animated fly-by pass that works while parked, and a six-view walkaround. Each mode has its own controls. Fly-by supports pass distance, height, side offset, duration and optional back-and-forth repetition; walkaround supports timed advancement and looping.
- Import profile JSON files through the displayed imports folder: add files in Explorer, Refresh, select and Import. Pasted profile code remains available. Export lets you choose a saved profile.
- A320 starter profiles, updated default icons and an estimated tower fallback when scenery lacks a usable tower position.
- Save confirmation uses the simulator's supported UI chime, with a Test sound control. Spoken recording is available only in the browser preview.
- Faster saves skip unchanged disk writes and avoid reparsing the complete library and rewriting every profile export. Changed saves still write and verify the recovery store.
- Updated illustrated manual and Cessna 152 import-test profile.

## Validation and limitations

162 native tests and 6,378 checks passed. Packaged browser tests cover global tracking and airport libraries, regeneration confirmation, animated fly-by controls, compact dialogs, opacity, icons, repeated adjustment, imports/exports, update detection and save-feedback routing. The release module is compiled with MSFS SDK 1.7.3.

Live flight verification of this complete release is still pending. Please test motion views, transparency, folder enumeration and sound in your simulator. Exterior views currently retain cockpit audio; A320 starter framing needs adjustment for each aircraft variant. The panel cannot open a native Windows file picker. Estimated tower cameras should be repositioned to the actual tower.

The Windows installer is unsigned. The tester bundle includes the PDF manual, guide, build information and checksums.
