# FS Camera Studio 0.5.2

Automatic update notifications and click-to-update for MSFS 2024 and XP Camera Studio for X-Plane 12.

**Install FS-Camera-Studio-0.5.2-Setup.exe once to enable the updater.** Close the simulators, run setup and keep
MSFS, X-Plane or both selected as desired. Saved profiles and native bindings are preserved.

## Updates

- Automatic release checks while the editor or mini panel is open, with a six-hour interval and retry backoff.
- A visible editor notification, version badge and mini-panel update button. Later dismisses the current notice;
  preferences and cached update information survive reopening. Automatic checks can be disabled in Settings.
- **Update now** opens the Windows updater. It verifies the official download's size and SHA-256, waits for both
  simulators to close, then upgrades your existing installation. **It never installs without your click.**
- Cancel is available until setup starts. The updater preserves installed simulator choices and folders, reports
  failures and verifies the installed version before reporting success. Existing setup backup rules remain.
- **Download installer**, release notes and a Start-menu **Check for updates** shortcut are available as fallbacks.

XPCS launches the updater directly. MSFS requests a registered Windows update link; that handoff still needs a
live simulator check. Use Download installer if it does not open. The bundled updater supports normal Windows
releases. All 0.5.1 camera, traffic and key-assignment improvements remain included.

Automated validation is recorded in the [verification record](https://github.com/Devinci297/FS_Camera_Studio/blob/main/doc/test-evidence/2026-11-07-v0.5.2.md).
