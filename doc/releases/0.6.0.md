# FS Camera Studio 0.6.0

Aircraft-aware inspection walkarounds for X-Plane 12 and Microsoft Flight Simulator 2024.

- Study the aircraft footprint and generate inspection stops around the fuselage, nose, wings, engines, landing gear and tail. X-Plane reads the loaded ACF automatically. MSFS accepts an imported configuration study or a locally generated catalog from readable aircraft configuration files.
- Walk along rounded paths at walking speed, look ahead into turns, ease toward inspection points and look around before continuing. Walking speed, effects, dwell, scan angle and repeat are adjustable; set effects to 0 to disable footstep motion.
- Improved compatibility with complex aircraft, including the ToLiss A319. Geometry generation passed checks on 34 installed X-Plane variants.
- Removed the dark rectangular backdrops behind inspection and import panels. Invalid routes cannot be added.
- Retired the old fixed-view walkaround playback. Existing profiles with a new inspection automatically lose the duplicate legacy Walkaround category while retaining other views.
- Traffic Auto nearest chooses nearby airport viewpoints; External offers front, rear, left, right, overhead and orbit views. Manual adjustments, pause and recenter are supported.
- Restored Primary/Secondary X-Plane camera-key assignments, aircraft controls-profile detection, focus capture and conflict review.

One Windows installer updates MSFS 2024, X-Plane 12, or both. Close the simulators before installation; profiles are preserved by setup. The normal profile upgrade retires superseded legacy walkaround views. Back up customized profiles before upgrading.

X-Plane requires 12.4.4 or newer on Windows x64. The public MSFS installer contains no machine-specific aircraft catalog: use Import aircraft source when geometry is unavailable. Protected or incomplete aircraft configurations require an imported study. Flight-model geometry may differ from the visible model; scenery and animated surfaces are not collision tested.

Automated validation is recorded in the [verification record](https://github.com/Devinci297/FS_Camera_Studio/blob/main/doc/test-evidence/2026-11-07-v0.6.0.md). Final live-simulator visual acceptance remains pending.
