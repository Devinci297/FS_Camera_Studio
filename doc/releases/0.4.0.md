# FS Camera Studio 0.4.0

Download **FS-Camera-Studio-0.4.0-Setup.exe**, close MSFS, and run setup over the existing installation. Saved
profiles, airport libraries, bindings and settings are preserved and upgraded. Existing installations can discover
this release through **Settings > Saving & updates > Check for updates**. The tester ZIP also includes the
illustrated manual, guide, build information and checksums.

**Before upgrading, export any profile you care about (Profiles > Export profile).** 0.4.0 saves profiles in
schema version 4. Version 0.3.0 reads only versions 1 and 2, so rolling back to 0.3.0 cannot open profiles that
0.4.0 has saved. Exported copies made before the upgrade can still be imported into 0.3.0.

## Changes

### Camera feel

- **Follow horizon:** a per-camera slider from 0 (follow the aircraft's bank) to 1 (stay level with the horizon)
  replaces the old level-horizon switch.
- **Flight effects everywhere:** turbulence, runway bumps, touchdown, acceleration and engine vibration now also
  apply to exterior and orbit views at half strength. Off, Subtle, Realistic and Action presets set every effect at
  once; a changed slider shows Custom.
- **Head movement in the cockpit:** neck lag, a lean into turns (up to 4 degrees), a taxi bob and an optional idle
  sway, each with its own strength.
- **Mounted action cam:** a camera mode fixed to the airframe, with a Locked, Level horizon or Heading only
  gimbal, plus optional airframe vibration.
- **Binoculars:** hold **Ctrl+Alt+Z** to zoom in; release to return to the normal field of view.
- **Glance views:** hold **Ctrl+Alt+G** to look at an instrument and snap back on release. **Ctrl+Alt+I** steps to
  the next glance view and **Ctrl+Alt+U** returns.
- **Panic release:** **Ctrl+Alt+X** hands the camera back to MSFS at once, with a confirmation message.

### Cinematics and world cameras

- **Cinematic mode (Ctrl+Alt+K):** picks views automatically by flight phase, holds each for 8 to 20 seconds, and
  mixes drift and cuts. Hold times, cockpit share, cuts and drift are in Settings.
- **Vantage points at any airport:** nearby airports get a temporary set of tower (or virtual tower), runway end,
  stand, fence-line and 1 NM approach spotting views. They stay temporary until you save them as an airport set.
- **Free drone cameras:** **Drop drone here** places a world-fixed camera at the current view or behind the
  aircraft. Fly it with the movement keys, optionally let it follow the aircraft, and it never goes below the
  terrain.
- **Gamepad drones:** an Xbox-style gamepad flies drone views with no setup, like the simulator's drone camera:
  left stick moves, right stick turns and looks, triggers climb and descend. Sticks, throttles and pedals are never
  picked automatically; assign any axis in **Settings > Gamepad**. The aircraft is masked from those axes only
  while a drone view is on screen.

### Traffic spotting

- **Traffic tab:** AI, FSLTL, VATSIM, IVAO and SayIntentions aircraft within the spotting radius, with status,
  distance, altitude and speed, and a button for each view. MSFS's own multiplayer aircraft are not visible to add-ons.
- **Spotting views:** follow any listed aircraft from the tower, a runway end, chase, fly-by, the camera on screen,
  or a saved spot. Tower and runway views are computed from airport data, so they work with no airport cameras
  and no camera profile. Runway ends are chosen by phase: the landing end for arrivals, the far end for
  departures.
- **Spots:** pick an airport, runway end (or Auto) and type (fence line, approach, threshold side or custom), adjust
  behind, side and height live, or **Save current view as a spot**. Spots are saved with your settings, not a
  profile.
- **Auto-spot (Ctrl+Alt+J)** follows arriving and departing traffic at the loaded airport automatically.
  **Ctrl+Alt+T** next target, **Ctrl+Alt+Y** previous target, **Ctrl+Alt+O** return to your own aircraft.

### Panels

- **Pop out:** a button beside Compact moves the editor into its own window for another monitor. It only appears
  when the simulator allows that window to pop out; **Dock** brings it back.
- **Mini panel Traffic tab:** the traffic list and spotting views in the bottom dock, with a fixed filter bar
  (All, Departures, Arrivals, On ground, Cruise, with counts) and a callsign/type search.
- **Icons-only categories:** click the mini panel's category divider to collapse categories to icons; click again
  to show labels.
- **New icons** for walkaround, fly-by, cinematic, spotting, drone and pop-out.

### Fixes

- Panels no longer call the camera module while MSFS tears a view down, which stopped a CoherentUIGT crash when
  closing or switching panels.
- Panel text uses ASCII only, because the simulator's font lacks several symbols; ATC prefixes such as `$$:` are
  removed from traffic names.

All new default keys use Ctrl+Alt and do not collide with existing defaults. Saved custom bindings are kept as
they are, so an existing custom assignment can prevent a new default from being added.

## Validation and limitations

Built with MSFS 2024 SDK 1.8.1. The release passed **309 native tests (75,190 checks)** on the release PC and the
browser UI test suite; see [the 0.4.0 verification record](../test-evidence/2026-11-07-v0.4.0.md). The installer
script is unchanged since 0.3.0, but its isolated lifecycle tests were not re-run for this build. Browser checks
verify UI behavior in a test environment; they do not prove live flight behavior.

Simulator coverage so far: the phase 1 build and the camera-feel build each flew about 20 minutes without a crash,
and the first spotting build flew 32 minutes without a crash with FSLTL traffic. Its findings (still parked
targets, smooth chase on FSLTL traffic, computed tower/runway views) are fixed in this release.

Still needing live simulator confirmation: head movement strength, mounted camera pitch direction, binoculars below
30 degrees, cinematic phase thresholds, temporary airport vantage points, free drone flight and terrain floor,
gamepad axis detection and aircraft masking, chase and fly-by smoothness on moving traffic, runway end selection,
live spot editing, Pop out visibility on your setup, and the mini Traffic filter bar. Exterior views can retain
cockpit audio. The simulator panel uses the imports folder or pasted code because it cannot open a native Windows
file picker. The Windows installer is unsigned.
