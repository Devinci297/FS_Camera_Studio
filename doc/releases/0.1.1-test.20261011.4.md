## What's changed

- Full-width, shorter mini panel with visible category groups and scrolling camera lists.
- Cleaner main header, tooltips throughout both panels, and corrected mini background opacity and extra backdrop.
- Icons, labels and both display choices apply only to categories; camera names and icons remain visible.
- Global Auto switch selects the nearest camera in the loaded airport camera set, including from cockpit views. Newly generated airport cameras track aircraft heading and pitch by default.
- Q/E altitude and left/right Shift speed-boost handling improved for airport cameras, preserving custom assignments.
- Bindings start collapsed and the expand/collapse label reflects the visible groups.
- Export profile now lists saved profiles and offers the current edited copy separately. Import now waits for the simulator's asynchronous save and reports completion correctly.
- Included 12-view A320 starters for default/iniBuilds A320neo, FlyByWire A32NX and Fenix A320. Each uses the aircraft's own pilot eyepoint and separate saved profile. Existing profiles are preserved.

## Install or update

Download **FS-Camera-Studio-0.1.1-test.20261011.4-Setup.exe**, close MSFS, then run setup. Saved camera profiles are preserved. Existing tester installations can find this release under **Settings → Check for updates**.

The ZIP includes the same installer, illustrated PDF manual, tester guide and checksums. The Windows installer is unsigned.
