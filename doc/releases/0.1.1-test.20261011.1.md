# FS Camera Studio 0.1.1 tester release

Camera Studio now includes an offline Windows installer, an illustrated ten-page manual, version information in
the app bar, and update detection with an installer-download handoff from Settings.

## Included

- Camera editing with direct names, icons/colors, category defaults, compact direction controls and orientation arcs.
- Smooth right-drag mouse look, sensitivity/smoothing controls, per-camera release/recall policies, view-relative
  WASD movement, Q/E height, Shift speed boost, scroll zoom, configurable bindings and Ctrl+S Save views.
- Scenery-based airport camera generation from Camera library +, editable world views, aircraft tracking options,
  nearby saved-airport loading, optional automatic viewpoint switching and a bounded scrolling mini panel.
- Camera binding slots beyond the previous 20-view limit and per-camera simulator head-tracking controls.
- Nearby airport discovery requests the scenery ICAO field instead of treating a short list identifier as final.
  This targets the reported MCO/KMCO display problem without renaming saved profiles.
- Per-user setup with Community-folder detection, package backups, repair/uninstall and running-simulator protection.

## Downloads

Use **Testers.zip** for the installer, illustrated PDF manual, quick guide, build information, notices and checksums.
The setup EXE and PDF are also attached separately. Close MSFS before installation. Existing saved profiles are
preserved. Keep only one active package; setup refuses linked package folders managed by Addons Linker/development tools.

## Verification and limits

117 native tests / 5401 checks passed. Packaged updater, airport generator and flight-controls UI checks passed.
The actual shipping installer passed nine isolated lifecycle scenarios. All ten PDF pages were rendered and reviewed.

This is an **unsigned prerelease for testers**. Live flight loading, scenery elevations, physical head tracking,
the nearest-airport ICAO response and MSFS update browser handoff still need in-simulator confirmation.
The release preserves the known-loading toolbar host; broader development host changes are not silently substituted.
Updates download through the browser; installation is performed by setup after MSFS is closed.

When reporting an issue, include the full build ID, MSFS version, aircraft, airport/scenery, exact steps and whether
it happens with the editor/mini panel hidden or after Release camera.
