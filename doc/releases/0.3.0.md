# FS Camera Studio 0.3.0

Download **FS-Camera-Studio-0.3.0-Setup.exe**, close MSFS, and run setup over the existing installation. Saved
profiles, airport libraries, bindings and settings are preserved. Existing installations can discover this
release through **Settings > Saving & updates > Check for updates**. The tester ZIP also includes the
illustrated manual, guide, build information and checksums.

## Changes

- **Clearer camera library:** distinct category headers and indented, compact camera rows, aligned counts/actions,
  inline shortcut badges and a separate active-camera indicator. The mini panel remains a wide bottom dock and
  shows starred cameras only. Main-panel category and camera names always remain visible.
- **Two bindings per action:** independent Primary and Secondary slots support keyboard and controller inputs
  together. Replacing or clearing one preserves the other. Conflicts offer replacement, the footer stays visible,
  and badges show the actual assignment.
- **Controller capture:** select the controller from a visible in-panel list, then listen for a button or hat
  direction. Button release or returning the hat to center completes capture. The hat-release subscription fix
  prevents a hat input from leaving capture stuck and blocking subsequent buttons. Mapping failures report an
  error and diagnostic detail; manual button/hat testing remains available.
- **Global airport defaults:** tracking mode, distant-target horizon protection, auto zoom with framing size,
  FOV limits and response time, plus heights for runway, gate, apron, taxi and tower categories. Each airport
  camera can override settings separately or return to inherited defaults.
- **Terrain-aware framing:** tracking and auto zoom use the camera's reported world altitude after simulator
  terrain-floor correction. Optional horizon protection levels distant lower targets while retaining heading.
  Saved placement remains separate from readback correction.
- **Use a profile with any aircraft:** Copy for current aircraft creates a separately matched copy of a saved or
  imported profile. Source profiles and shared airport views remain intact; adjust positions for the destination
  cockpit geometry.
- **Editor polish:** reorganized global controls and Settings, clearer inherited values, compact context menus,
  responsive binding dialogs, and distinct aircraft/profile and airport-library scopes.
- Updated documentation, screenshots and illustrated manual for 0.3.0.

Existing features include shared airport libraries, global Auto switch, head tracking off by default, heading
and pitch tracking on by default for eligible views, orbit/animated fly-by/walkaround, profile file-folder import,
copy/paste camera settings, hold-to-adjust controls, independent panel opacity and native save confirmation chime.

## Validation and limitations

The release passed **191 native tests and 7,004 checks**, **42 UI test files**, and **nine isolated installer
scenarios**. The shipping installer also refused to replace a package while MSFS was running. Release
build/package evidence is recorded in
[the 0.3.0 verification record](../test-evidence/2026-10-11-v0.3.0.md).
Browser checks verify UI behavior in a test environment; they do not prove physical controller or live flight behavior.

The latest **T.16000M hat-release correction still needs a physical-controller retest**. Capture a hat, then
listen for a normal button, and confirm a saved hat movement binding stops on centering. Live scenery tracking,
opacity and audible save feedback also require simulator verification. Horizon protection does not remove
terrain/building occlusion. Exterior views can retain cockpit audio. Starter and copied profiles may require
position adjustment. The simulator panel uses the imports folder or pasted code because it cannot open a native
Windows file picker. The Windows installer is unsigned.
