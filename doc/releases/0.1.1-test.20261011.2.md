# FS Camera Studio 0.1.1-test.20261011.2

This tester update addresses airport tracking and zoom, scenery stand names, and mini-panel layout.

## Changes

- Airport cameras can target the user aircraft while keeping their world position fixed. Heading-only tracking keeps the latest aircraft position through telemetry gaps; right-drag temporarily overrides tracking.
- Corrected overlapping simulator zoom-event subscriptions that could cancel or double mouse-wheel zoom.
- Camera directions are configured automatically. The manual axis-check controls and their subjective corrections have been removed.
- Reduced the mini panel from 164 to 120 pixels high, with independently scrolling camera/category lists. Tracking choices open above the dock with clearer labels and selected states.
- Generated stand names now include scenery gate letters, numbers, suffixes and directional parking names. Different suffixed stands remain separate; vehicle-only positions are excluded.
- Updated the illustrated manual and tester guide.

## Install or update

From the previous tester build, click the version in the app bar or open **Settings > Version & updates**, then **Check for updates** and download the installer. Close MSFS before running setup. Saved profiles are preserved.

Alternatively, download **Setup.exe** below. **Testers.zip** includes setup, the illustrated manual, quick guide, build information and checksums. Keep only one active package; setup refuses linked package folders managed by Addons Linker/development tools.

Existing saved airport cameras are not silently renamed. Generate a new preview to inspect the corrected scenery names. Preserving existing views keeps custom names and poses; replacing generated views replaces those edits.
