# FS Camera Studio 0.5.0 (draft)

Draft notes for the first release that includes X-Plane 12. The version number is provisional until the release is
prepared; nothing here is tagged or published yet.

Download **FS-Camera-Studio-0.5.0-Setup.exe**, close the simulator, and run setup. The components page now offers
**Microsoft Flight Simulator 2024**, **X-Plane 12** or both. An MSFS upgrade keeps its Community folder; saved
profiles, airport libraries, bindings and settings are preserved in both simulators. Existing installations can
discover this release through **Settings > Saving & updates > Check for updates**.

## X-Plane 12: XP Camera Studio

The same camera manager for X-Plane 12.4.4 and newer, as a native plugin. It runs the same module logic as the MSFS
version and shows the same editor and mini panel in X-Plane's own browser windows.

- **Open it** from Plugins > XP Camera Studio, or with the `xpcs/toggle_editor` and `xpcs/toggle_mini` commands.
  The mini panel shows on hover at the bottom of the screen; the editor can be popped out to its own window.
- **Cameras:** cockpit views move the pilot's head, so the 3D cockpit stays clickable. Exterior, orbit, fly-by,
  airport and spotting views are drawn by the plugin. Choosing another X-Plane view hands the camera
  back. A C172 starter profile is created for the Laminar Cessna 172.
- **Bindings are X-Plane commands:** every action is an `xpcs/` command (`xpcs/view_1` to `xpcs/view_30`,
  `xpcs/peek_1` to `xpcs/peek_30`, `xpcs/next_camera`, `xpcs/glance_hold`, `xpcs/spot_next` and more). The Bindings
  tab lists each one with Copy; assign keys and buttons in X-Plane's Keyboard and Joystick settings. Read-only
  datarefs (`xpcs/camera_active`, `xpcs/active_view`, `xpcs/active_camera`, `xpcs/fov_deg`, `xpcs/cinematic`,
  `xpcs/auto_spot`, `xpcs/editor_open`, `xpcs/mini_open`) are published for cockpit builders and scripts.
- **Airport cameras** come from X-Plane's scenery: every enabled pack in `scenery_packs.ini` plus Global Airports,
  with X-Plane's priority. Runways, the tower viewpoint, gates and parking, the taxi network and taxi signs are read
  from `apt.dat`. Airport cameras stay above the terrain.
- **Spotting** follows X-Plane's AI traffic and aircraft that multiplayer and traffic plugins publish to X-Plane's
  TCAS targets, with the same tower, runway, chase, fly-by and track views.
- **X-Camera import:** Profiles > Import lists X-Camera's camera files for the loaded aircraft and converts one into a
  new profile.
- Profiles are saved in `X-Plane 12/Output/preferences/XPCameraStudio`.

## Installer

- One setup for both simulators, with a folder page for each. X-Plane 12 is found from X-Plane's own install list or
  Steam libraries.
- An existing X-Plane plugin folder is backed up and hash-verified before it is replaced by a clean copy. Every
  installed file is verified after setup. Setup refuses to run while X-Plane or MSFS is running.
- Uninstall removes the MSFS package and the X-Plane plugin and keeps profiles in both simulators.

## MSFS 2024

- Messages, update hints and help texts name the simulator in use.

## Known limits (X-Plane)

- Head tracking cannot be switched from Camera Studio in X-Plane yet; set it in X-Plane's own settings.
- Instrument close-up views in the C172 starter still need fine tuning.
- Windows only; a Mac build is planned later.
