# Starred cameras in the mini panel

The mini panel displays only starred cameras in the selected category. Category selection and the mini panel's previous/next buttons also use starred cameras. Categories remain visible even when empty; the panel explains how to add stars. The main camera library still shows all cameras.

Right-click a camera in either panel for **Assign key binding**, or to add/remove its star. The binding action opens the existing keyboard/controller assignment dialog and allocates a View ID if needed. Changes are saved using Save or Ctrl+S.

On the first load of a store written by an older version, all existing aircraft and airport cameras are starred to preserve their mini-panel visibility. The next changed save records this migration. Subsequent unstar choices survive save and restart. Historical backups are untouched; newly imported files retain their explicit star choices. New built-in cameras, generated airport cameras, and cameras added in the UI start starred.
