# Reuse a profile with another aircraft

Load the destination aircraft, then open Profiles and choose **Copy for current aircraft** beside the source profile. The same action is available immediately after importing a profile file or code.

Name the new profile and choose **Create copy**. The copy opens and becomes the preferred profile for the loaded aircraft. The source and existing destination profiles remain available. If the open profile has unsaved edits, the panel first offers Save, Discard, or Cancel.

This works for any loaded aircraft model, without an aircraft whitelist. Cameras retain their numeric position, orientation, zoom, motion and behavior settings, with new profile/category/camera IDs. Because cockpit dimensions and reference origins differ, adjust positions as needed. Copying is a starting point, not automatic cockpit geometry conversion.

Shared airport cameras remain separate from aircraft profiles. The camera-control aircraft match remains enforced: copying assigns the new profile to the destination model, while the original stays assigned to its source model.
