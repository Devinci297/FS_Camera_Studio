# FS Camera Studio 0.6.0 verification record

November 7, 2026. Release branch `codex/release-0.6.0`, based on 0.5.3 (`16e77fe`). The isolated release checkout includes aircraft inspection, motion smoothing, retirement of legacy walkaround playback, panel fixes, traffic viewpoints and X-Plane keyboard assignment fixes.

## Builds and payloads

- Version 0.6.0 in VERSION, CMake, native build definitions, panel metadata and package manifest.
- Frozen native inputs: `build/release/0.6.0/native-source-freeze.json`; release receipt: `build/release/0.6.0/staged.json`.
- Rebuilt Windows x64 X-Plane plugin and MSFS WASM using SDK 1.8.1. The SDK toolbar compilation completed and the reviewed host and its hash receipt were refreshed from that output. Existing compiler/SDK warnings remain.
- MSFS package: 30 files. X-Plane payload: 19 files. Shared runtime UI files match the release source byte for byte.
- Public package staging uses `-SkipAircraftStudy`. The aircraft catalog is the empty shared placeholder, not the developer's installed-aircraft data. X-Plane studies the loaded ACF automatically; MSFS requires an imported configuration study or a locally generated catalog where no geometry is available.
- Shipping and test-harness installers contain identical simulator payloads and updater hashes. The harness uses separate registration, protocol, support folders and fake simulator folders.
- Nine distribution assets, with SHA-256 checksums, ZIP CRC validation and archive/loose-file identity checks. The installer remains unsigned.
- Regenerated the 22-page PDF manual from current packaged-UI captures. Rendered every page, inspected the contact sheet and the new aircraft-inspection page at full size. These are browser previews, not in-simulator acceptance screenshots.

## Automated checks

- **339 shared native tests / 99,678 checks** and **11 X-Plane keyboard tests / 53 checks** passed: 350 tests / 99,731 checks total.
- **70 UI suites passed.** Three motion-related fixtures were updated to provide synthetic aircraft geometry and confirm the footprint preview before adding views. An initial follow-horizon fixture still expected immediate legacy preset creation; after the same fixture correction, its focused rerun passed. No runtime change was needed for these test updates.
- **55 updater checks passed**, covering metadata, trusted URLs, hashes, failure handling, cancellation, file locking, deferred installation and installer failure. This run used isolated fixtures; it did not perform a network installation.
- **17 isolated installer scenarios passed**, covering both simulators, install/repair/upgrade/uninstall, preservation of unrelated files, folder/link validation, process guards and stored installation preferences. Evidence: `build/installer-tests/4355a169-26e2-4644-8de9-ebb801d2c20a/results.json`. The optional historical development-package receipt was absent, so that separate comparison was skipped. No test targeted a real simulator installation.
- Aircraft geometry checks passed for 34 installed X-Plane variants, including ToLiss A319/A340, FlightFactor 777, Zibo 737, MD-11, Concorde, B2707 and Laminar aircraft. The two legacy XP11 A319 files had no usable body geometry; they were rejected, not substituted.
- A read-only copy of the user's A319 profile validated with 45 cameras and 6 categories after retiring its 18-camera legacy Walkaround group. Tests cover idempotence, default-camera repair, preserving unrelated cameras and studied routes, and synchronizing removals to both panel mirrors.
- Inspection regressions cover curved route clearance, acceleration, anticipatory heading, smooth stationary head turns, shared gear approaches, pause/frame gaps, parking brake guards and manual interruption. Legacy fixed-view categories cannot start the inspection command.

## Acceptance and limits

The local builds were installed for user testing during development. The user reported the earlier complex-aircraft rejection, backdrop and duplicate-route problems; the recorded automated tests reproduce those cases and verify the fixes. Final live visual acceptance of this release across aircraft and simulators remains pending.

ACF/configuration geometry can differ from visible models. Protected or incomplete MSFS configurations need imported geometry. Scenery, animated surfaces and visual-only parts are not collision tested. No agent-controlled simulator flight or user-screen automation was used for release acceptance.
