# 0.1.1-test.20261011.1 tester release

- Native suite: 117 passed, 0 failed, 5401 checks.
- SDK 1.7.3 WASM Release module compiled in `build/wasm/release-0.1.1`.
- Packaged updater, airport UI and flight-controls browser checks pass.
- Nearby scenery list identities now request the airport facility's `ICAO` field and apply it only when region,
  short ident and position match. Regression covers MCO -> KMCO, local identifiers, international identifiers,
  position mismatch and unchanged profile data. Live KMCO response still requires MSFS verification.
- App bar version and Settings update check use the public GitHub releases endpoint. Tester releases are included
  for tester builds; versions are compared numerically. Only exact installer assets from this repository qualify.
  Errors/timeouts are not reported as up to date. Download uses the simulator's `OpenBrowser` with a selectable URL fallback.
- Browser tests cover channel filtering, draft exclusion, version ordering, foreign URL rejection, HTTP error,
  current-version and update-found states, and the handoff argument. Live MSFS HTTP/browser handoff remains unverified.
- No HTTP or installer operation runs in the native simulator frame loop. Setup requires MSFS stopped.
- Nine isolated installer lifecycle scenarios pass with the named test-process harness, including PDF installation:
  `build/installer-tests/fe3d430a-342c-490a-8df8-8b353839bd8a/results.json`.
- Once MSFS was closed, the shipping EXE passed all nine scenarios as well, including its process-name guard tested
  with a named sleeper: `build/installer-tests/2b75f349-b446-4b97-82ed-32c068bb0d88/results.json`.
- Ten-page PDF manual rendered and all pages visually reviewed; page 8 corrected to use a close-up mini-panel image.
  Source and screenshots are committed; PDF is included in the release and installer.
- The shipping package uses the frozen known-loading host, not the unqualified full development host. Staging does
  not alter the currently installed package. Source baseline and hashes are under `package/validated-host*`.
