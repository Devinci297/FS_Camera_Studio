- Helper lifecycle checks passed: missing helper, stale preview, changed native conflict, cancel/retry, another

- All **16 isolated installer scenarios passed**, including both simulators separately/together, upgrade repair,
  backup verification, stale-plugin cleanup, unrelated-file preservation, junction/duplicate refusal, invalid
  targets, uninstall and named-process guards. Evidence:
  `build/installer-tests/8d088f27-c413-4d2c-848c-3f54b3ff291d/results.json`.
  The historical development-package receipt was absent, so that optional live-package hash check was skipped.

## Installed and live state

The earlier development X-Plane build was installed locally with a verified backup. The versioned 0.5.1 installer
was tested in isolated folders, not installed over the user's simulator copies. No manual flight test of 0.5.1
has been reported. BUILD-INFO retains `liveSimulatorVerified: false`. Publication authorization is separate from
live acceptance. Native key assignments require X-Plane to exit and restart with the selected controls profile.
