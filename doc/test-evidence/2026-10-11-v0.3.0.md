# FS Camera Studio 0.3.0 verification record

Date: October 11, 2026. This record separates automated release verification from live MSFS acceptance.
Historical diagnostic and 0.2.0 evidence remains unchanged.

## Source and build

- Release version: `0.3.0` (`VERSION`, package manifest and panel metadata must agree).
- Release native result: **191 tests passed, 0 failed; 7,004 checks**.
- SDK baseline: MSFS 2024 SDK 1.7.3.
- Reviewed host: `package/validated-host`; receipt `package/validated-host.json`.
- Native input freeze and release stage: `tools/diagnostics/stage-v0.3.py`.
- Module output: `build/wasm/release-0.3.0/FSCameraStudio.wasm`.
- Staged package: `build/release/0.3.0/fs-camera-studio`.
- Stage receipt: `build/release/0.3.0/staged.json`.

The stage command validates native input hashes against the freeze before copying the module. The distribution
builder checks staged package hashes rather than packaging an arbitrary working directory. Receipts and test
logs are build artifacts; only their recorded successful results establish a completed check.

## Reproduction

```powershell
python tools/diagnostics/stage-v0.3.py --freeze
cmake --build --preset tests
ctest --preset tests
tools\build.ps1 -ModuleOnly -OutputDirectory build/wasm/release-0.3.0
python tools/diagnostics/stage-v0.3.py
python tools/build-manual.py
python tools/build-installer.py --version 0.3.0 --package build/release/0.3.0/fs-camera-studio --receipt build/release/0.3.0/staged.json
```

Regenerate release screenshots before the manual when changing UI content. Inspect the rendered PDF and
screenshots for clipped text, stale versions and misleading simulator imagery. Manual screenshots are browser
fixtures, not live flight evidence. The installer guide describes isolated lifecycle and running-process tests.

## Regression coverage

- Native: global tracking and sparse airport overrides, height inheritance, terrain readback, horizon protection,
  zoom smoothing, cross-aircraft copying and persistence, primary/secondary inputs, held-input release, controller
  capture cancellation/timeouts, POV center handling, and explicit hat down/up registration.
- Packaged UI: `airport-camera-settings.test.cjs`, `cross-aircraft-profile.test.cjs`, `dual-bindings.test.cjs`,
  `hat-capture.test.cjs`, `binding-dialog-layout.test.cjs`, `library-layout.test.cjs`,
  `starred-mini-context.test.cjs`, and global-controls/settings/editor regression suites under `ui/tests`.
- Packaging: source freeze, staged manifest/layout, payload hashes, version agreement and distribution checksums.
- Installer: isolated install/repair/uninstall lifecycle and refusal to replace a package while MSFS is running.

## Completed release artifact checks

- Versioned native build passed 191 tests and 7,004 checks (`build/release/0.3.0/native-tests.txt`).
- SDK 1.7.3 WASM compilation succeeded (`build/release/0.3.0/wasm-build.txt`).
- The illustrated manual has 15 pages; every page was rendered with Poppler and visually inspected. All 12 previous screenshots were refreshed and six added. Screenshots explicitly use browser fixtures.
- The isolated installer harness passed nine install/repair/uninstall and rejection scenarios, preserving the actual installed package and profile fixture (`build/installer-tests/138b49b8-8ed0-4f2c-b365-b881f15f8989/results.json`).
- The shipping EXE refused installation while MSFS was running (exit 7) and left the isolated target untouched (`build/release/0.3.0/shipping-guard/result.json`).
- Both repository example profiles passed native validation: C152 (12 cameras, 3 categories) and C172 (20 cameras, 5 categories). The tester bundle includes the C152 import example and its checksum.
- All 42 UI test files passed against the frozen packaged host, with additional source-host and JavaScript syntax checks (`build/release/0.3.0/ui-test-results.json`). A narrow-sidebar camera-label overlap found during this pass was corrected before the final screenshots, manual, stage and installer were rebuilt.
- All 26 staged package files, distribution checksums, ZIP members and the final 15-page PDF were verified (`build/release/0.3.0/distribution-verification.json`). The shipping bundle identifies version 0.3.0 and is not an installer test harness.
