## Acceptance and compatibility

The updater downloads and verifies before asking to restart. Only explicit **Restart and install** approval calls the normal Windows close request; there is no forced termination. **When I close the sims** waits without requesting closure. Installation waits for both simulators and the key helper, verifies the resulting build metadata, and then reopens only simulator executable paths captured by an approved close request.

These behaviors have automated and isolated installer evidence. Actual simulator close/reopen and a future-version upgrade from inside either simulator still require live acceptance. The MSFS OpenBrowser handoff to the custom Windows protocol remains unverified live; XPCS launches the helper directly. Start-menu Check for updates and recovery download remain available. No computer-use tools were used.

Older installations need this setup once because they do not contain the new helper and installation record. This release task did not install over the user's real simulator copies, claim a loaded version change, or claim live flight acceptance.
